## 15. 手順書

### 15.1. デプロイ環境の構築 [想定作業時間: 3時間]
#### 15.1.1. デプロイ環境の構築
- [ ] WSLを立ち上げ、下記ディレクトリへ移動する。
```text
lxp-practical-project/drone
   ```
- [ ] README.mdに従って、Dockerを起動する。
```text
$ docker-compose up -d
$ docker exec -it　digitalojt-drone /bin/bash
   ```
  - [ ] bash-4.4#と表示されたら、アプリを起動する。
```text
# ./gradlew wrapper --gradle-version 7.4
# ./gradlew build
# ./gradlew bootRun
   ```
  - [ ] http://localhost:8080/ を開き、ドローン生産在庫管理システムの画面が正常に
表示されることを確認し、Ctrl+Cで中断する。
#### 15.1.2. ソースおよびデプロイ
  - [ ] DOJT用に払い出されたアカウントを使い、AWS App Runnerの管理画面にサインインする。

- [ ] サービスの作成を選択する。

- [ ] 「ソースコードリポジトリ」を選択してGitHubと連携する
GitHub連携の「ソースディレクトリ」は「/drone/dev」を指定する

- [ ] デプロイ設定
「自動」を選択する
#### 15.1.3. 構築を設定
- [ ] ランタイムは「Corretto 11」を選択する
- [ ] AppRunner 上ではビルドコマンドとスタートコマンドを設定する。
```text
$ ./gradlew bootJar && cp build/libs/dev-0.0.1.jar ./
$ java -jar ./dev-0.0.1.jar
```
- [ ] 任意のサービス名を入力し、デプロイする。

期待する成果
Java マイクロサービスをデプロイするために、App Runner が構築できていること。
VPCなど必要なネットワーク設定ができていること。

### 15.2. ロギングとモニタリングの設定 [想定作業時間: 3時間]

- [ ] AWS CloudWatchの管理画面を開く。
- [ ] 画面左ナビゲーションペインから以下の順番でクリックする。
ダッシュボード＞ダッシュボードの作成
- [ ] 任意のデータ型とウィジェットタイプを選び、次へを選択する。
### 15.3. インフラコスト管理の設定 [想定作業時間: 3時間]
- [ ] AWS Billing and Cost Managementの管理画面を開く。
- [ ] 画面左ナビゲーションペインからCost Explorerをクリックする。
- [ ] レポートパラメータを任意のサービス・リージョンで絞り込み、レポートライブラリに保存する。
- [ ] 画面左ナビゲーションペインから予算をクリックする。
- [ ] 予算を作成をクリックする。
- [ ] 予算の設定
「テンプレートを使用(シンプル)を選択する。
- [ ] テンプレート
「月次コスト予算」を選択する。
- [ ] 任意の予算名と予算額(少額)を入力する。
- [ ] 受信者に自分のアドレスを入力し、「予算を作成」をクリックする。
  
期待する成果
Cost Explorer でコストを監視、顧客からの要望があればレポート・CSVデータで出力できること。
予算超過したら管理者にアラートがメールで通知されること。
